# Countdown — Cuentas regresivas personalizadas

Páginas web de cuenta regresiva para cumpleaños, bodas, XV años y eventos. Sustituyen a la invitación digital: son más económicas, se hacen rápido, no necesitan fotos de calidad y llevan botón de WhatsApp para confirmar asistencia.

## Cómo se usa
1. Copia `index.html` y ábrelo en un editor de texto.
2. Edita el bloque `CONFIG` al inicio del script: nombre del evento, nombre de la persona, fecha y hora, mensaje y número de WhatsApp.
3. Súbelo a GitHub Pages y comparte el enlace.

## Ejemplo incluido
La plantilla viene con el cumpleaños de Isaac (29 nov 2026) como ejemplo. Cambia los datos en `CONFIG` y listo.

## Qué lleva
- Contador en vivo: días, horas, minutos y segundos.
- Botón de WhatsApp para confirmar asistencia (se oculta si no hay número configurado).
- Diseño para celular, sin dependencias externas: un solo archivo HTML.
